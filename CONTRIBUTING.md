# Cómo contribuir

Gracias por tu interés en mejorar esta práctica.

## Preparar el entorno

1. Haz un *fork* del repositorio y clónalo en local.
2. Instala PHP 8.2 o superior.
3. Ejecuta un script con `php aleatorios.php` para comprobar que funciona.

## Ramas y commits

- Crea una rama por cambio: `feature/nombre-corto` o `fix/nombre-corto`.
- Escribe los mensajes de commit en español, en presente y de forma breve,
  por ejemplo: `Añade validación de división entre cero`.

## Estilo de código

- Usa nombres de variables descriptivos.
- Revisa los archivos Markdown con `npx markdownlint-cli2 "**/*.md"`.

## Abrir una Pull Request

1. Sube tu rama a tu *fork*.
2. Abre una Pull Request hacia `main`.
3. Describe qué cambia y por qué.
